# Localgate Tap

## How do I install these formulae?

`brew install localgate/tap/<formula>`

Or `brew tap localgate/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "localgate/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
